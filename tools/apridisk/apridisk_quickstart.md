# Apricot software archiving with APRIDISK

###Download APRIDISK
Read the [APRIDISK Instruction manual](https://actapricot.org/support/apridisk/apridisk.htm) for APRIDISK first. it contains the operating instructions, copyright and important licensing information.

Then download [Download APRIDISK](https://actapricot.org/support/apridisk/apridisk.exe)

###Install APRIDISK
There is no installation program for APRIDISK so please create the following directory structure:

```
APRIDISK\        (put APRIDISK.EXE here)
APRIDISK\DISKS   (put the .DSK files here)
```

###Download the disks
Then download the correct disk from [Jonathan's Disk list](https://actapricot.org/disks/aprididx.htm) or [disk archives donated by Apricot users](https://actapricot.org/donated_disks/disk_list.htm)

###Obtain correct disks
If you need DS/DD 720K disks, please see the Apricot companies for DSDD floppy disk suppliers.

Please read the APRIDISK Instruction manual carefully before purchasing disks.
